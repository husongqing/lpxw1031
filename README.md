# 龙牌湘味 · 认领酱缸小程序原型

离线可跑的高保真交互原型，包含用户端（小程序）与后台管理端（likeadmin 风格）。

## 目录

- `index.html` —— 用户端原型（19 个页面），直接用浏览器打开即可
- `admin.html` —— 后台管理原型（认领订单 / 酿造记录 / 提货发货 / 退款审核等）
- `assets/css/` —— 设计系统与页面样式（`brand.css` 为品牌色板，`user.css` 为用户端，`admin.css` 为后台）
- `assets/js/` —— 交互逻辑（`user.js` / `admin.js`）
- `assets/img/` —— 图片资源（来源见 `assets/img/CREDITS.md`）

## 主要功能流程

1. 游客浏览品牌内容，认领 / 下单时触发微信授权登录 + 绑定手机号
2. 选择周期（1 / 2 / 3 年）完成认领支付
3. 月度酿造反馈（时间轴图文 + 月度媒体）
4. 家庭日节点报名
5. 分批提货（每年最多 4 次）+ 发货详情（快递单号）
6. 酱缸转期（剩余 ≥ 100 瓶，按单瓶差价补差）
7. 订单状态：待支付 / 待酿造 / 酿造中 / 已完成 / 已取消

## 部署

静态站点，`index.html` 作为入口，可直接部署到任意静态托管（如 EdgeOne Pages）。
